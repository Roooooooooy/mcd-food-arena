## 证据与文案边界

- “我就喜欢”的品牌宣言身份由官网正文直接确认；“麦乐鸡侠”的官方采用由官网历史活动规则直接确认。
- “麦门永存”的新浪页面确认的是该账号在显示的时间已经使用了这句话，不证明其为首创。“麦门”“每日一麦”“日行一麦”的界面新闻摘录是可信媒体引用证据；本次没有找到并核验这些文字的最早原帖，不应标注“最早出自”某个网友。
- 官方麦乐鸡页面描述的是2024年的限时活动。本次只借用已存在的梗名称，不借用“免费多1块”等优惠承诺。也不暗示网页能下单、改备注、领取赠品、购买多份或保证现价。
- 不使用肯德基的“疯狂星期四”“V我50”作为麦当劳梗。
- 不把自行拼出的“麦门认证”“麦门审判”“入麦成功”等变体列为已有梗。若最终页面使用其他新文案，应明确它只是普通说明文字，不能伪装成有出处的梗。
- 每日一麦、日行一麦属于同一段麦门文学中的两个表达；梗清单可以分别记录，但页面中不必为了数量同时使用。

## 实施时建议优先顺序

1. 主操作用`我就喜欢`，直接对应“我选这个”的意义。
2. 页面身份或氛围用`麦门`；完成后的轻松反馈用`麦门永存`。
3. 若候选确实包含麦乐鸡，才给相关餐品使用`麦乐鸡侠`标签。
4. 在`每日一麦`与`日行一麦`中选一个作为短装饰文案。
5. 最终交付应按实际页面列出确实使用的梗；这份文件是候选来源清单，不能当成“已全部用到”的说明。
