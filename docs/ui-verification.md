# 麦麦二选一 UI 优化

本轮由用户批准优化首页、二选一和最终餐单，并指定配色适配麦当劳。颜色参考 2026-10-15 读取的 [麦当劳中国官网样式](https://www.mcdonalds.com.cn/files/css/base.min.css?v=2026-01-12)：红色 `#DB0007`、黄色 `#FFBC0D`、深灰 `#2D2D2D`。背景采用暖白 `#FFFAF2`，辅助文字采用 `#665D52`。

- 红底白字对比度 5.23:1，黄底深灰 8.17:1，暖白背景上的辅助文字 6.21:1。
- 首页收短说明和装饰，菜单来源及餐品/顺序采用原生可展开区域；手机底部固定开始按钮，并给滚动与键盘焦点留出安全区。
- 二选一左右卡片与按钮同等突出；饮料逐规格参考价格默认可见，完整营养信息可展开。阅读详情时，左右方向键不会误选餐品。
- 餐单采用图片、名称和规格并排布局；手机单列，保留数量、移除、重选和合计。未计算、未知价格和条件价仍如实提示。

## 验证

201 项现有测试、类型检查和公开构建通过。独立源码审查及独立 201 项测试通过。

手机视口 375×812：来源区域从 233px 减为 66px；有旧记录时分类入口从约 845px 前移至 518px，开始按钮在约 745–799px，首屏可操作。双可乐对比中，小/中/大杯价格均可见，两侧选择按钮进入首屏，完整逐规格营养可展开。页面没有横向溢出。

对展开的餐品面板连续执行20次 Tab，实际交互控件均未被底部栏遮挡。手机结果页可将可乐改为大杯、数量2，参考合计为24.00元。查看详情时按右键未改变对阵、剩余候选或选择次数。

本轮只调整呈现及相关键盘保护，随机候选池、存档版本、官方数据和图片、MCP 调用与核价校验保留。截图保存在本机 `docs/screenshots/`；构建验证和实际公开发布分别确认。

## 整张卡面选择（2026-10-15）

用户确认：图片、名称、价格和留白都可选择；营养详情在卡片下方独立展开。卡面由一个原生按钮覆盖，保留“我就喜欢”、左右餐品名称及键盘可访问性。没有把交互控件嵌套在按钮中。正面和详情分两行，展开营养不改变两张正面的高度。

本轮浏览器验证：旧版本图片点击不推进（0→0）；新版本图片、名称、价格、留白点击各推进一次；双击只推进一次；Enter 和空格各推进一次；点击营养标题和正文不推进。OR 装饰覆盖位置原本不能选择，透传点击后同位置6→7，已修复。

375px 手机的两张卡面同高；双可乐的全部杯型价格直接显示，展开详情前后正面高度均为455.09px。点击可乐价格选择的是可乐，最终切换大杯、数量2，快照参考合计24.00元。320px 窄屏横向溢出已消除。

201 项原有自动化测试、类型检查及公开构建通过。新卡面交互另用实际浏览器验证；独立审查发现的徽章点击遮挡已修复并复验。随机候选池、菜单快照、数据、报价与存档校验保留。
