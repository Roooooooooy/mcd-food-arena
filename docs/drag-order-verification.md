# 分类拖拽排序验证

2026-10-15，按用户确认的手柄排序方案实现。该功能调整已选餐品分类的执行顺序，不重建或重新勾选候选餐品。

- 拖动手柄超过8px后拿起，浮层显示分类和已选候选数；其他行移动预览，松手才更新真实顺序。
- 拖动期间暂时收起候选展开区，结束或取消后恢复。上下移动按钮与候选勾选功能保留。
- Esc取消或指针在列表外松手保持原顺序。菜单上下文或已选候选变化时，旧拖动不能覆盖新选择。
- 键盘可空格拿起、上下移动、空格/Enter放下；有中文读屏提示，放下后手柄保留焦点。
- 48×48px手柄使用 `touch-action:none` 接收触摸移动，卡片其他区域仍可滚动。实际触屏设备未操作，不能将窄屏鼠标验证当作触屏手势验收。

## 实际浏览器结果

| 场景 | 结果 |
| --- | --- |
| 键盘预览 | DOM顺序未改，另两行出现位置变换、浮层显示，候选区暂时收起 |
| Esc取消 | 原分类顺序、展开区和16项勾选状态全部恢复一致 |
| 键盘放下 | 饮料移动到小食之前，焦点留在饮料手柄，原勾选保持 |
| 鼠标拖动 | 饮料由中间拖到首位，顺序变为饮料/主食/小食；已排除的餐品仍排除 |
| 列表外松手 | 顺序保持不变，无残留浮层 |
| 原上下箭头 | 饮料下移正常，仍可继续圈选餐品 |
| 开始及暂停 | 饮料第一类开始，15份已筛选候选；暂停后分类顺序仍为饮料/主食/小食 |
| 375px / 320px | 可用宽度360 / 305，滚动宽度相同；手柄均48×48px，箭头与圈选按钮不重叠 |

排序纯函数先以未实现逻辑运行：向上/向下移动与有效拖动用例按预期失败。实现后4项排序测试通过，覆盖候选保留、取消/原位、失效菜单/候选、重复或单分类。当前分支完整205项测试、类型检查、公开构建通过。
